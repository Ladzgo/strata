FAQ

Good questions.

Where does my data live?

On the web, your workspace is a SQLite database (running as WebAssembly) saved in your browser's IndexedDB for this site. It stays on this device and in this browser profile. Clearing site data deletes it, so use Settings → Back up workspace now and then to keep a copy.

In the Mac app, it's a SQLite file in your user's Application Support folder. In both cases it's never uploaded anywhere.

Does the AI need any setup?

No. The first time you use an AI feature on the web, Strata downloads a small open model (Qwen2.5 1.5B, about 900 MB) into your browser's cache, once, and runs it on your GPU with WebGPU. Your notes and prompts never leave the page; the model download is the only thing fetched. It works in recent Chrome, Edge and Safari.

Want bigger models? Install Ollama, pull one (for example ollama pull llama3.2), and start it with this site allowed. Strata switches to it automatically:

OLLAMA_ORIGINS="https://ladzgo.github.io" ollama serve

If the Ollama menu-bar app is already running, quit it first. Your browser may ask whether this page can reach devices on your local network; allow it. The Mac app uses Ollama and connects to it directly.

The Mac app says it can't be opened. Is it safe?

The v0.1.0 build isn't signed with an Apple Developer ID yet, so macOS warns you the first time. To open it:

  1. Open the DMG and drag Strata into Applications.
  2. Double-click Strata. When macOS blocks it, click Done.
  3. Go to System Settings → Privacy & Security, scroll down and click Open Anyway next to the Strata message, then confirm.

You only need to do this once. The build is for Apple silicon Macs (M1 and later).

Do I need an account, or the internet?

No account, ever. You need a connection once to load the page; after that, your workspace and editor run locally. The Mac app never needs the internet at all.

Can I get my data out?

Yes. Export pages as Markdown or HTML, databases as CSV, and your whole workspace as a JSON backup. Import Markdown, CSV or a backup in either the web or the Mac version.

Does the web version sync with the Mac app?

Not automatically. Nothing syncs, because there's no server to sync through. To move a workspace, export a backup from one and import it into the other.

What does it cost?

Nothing. There's no paid tier and nothing to upgrade to.
